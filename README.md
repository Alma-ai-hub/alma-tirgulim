# מילה במילה

מכניסים 10-20 מילים (בעברית, באנגלית או גם וגם), ומקבלים:

- **10 דפי עבודה להדפסה**: כתיבה חוזרת, מילים במשבצות, שתי תפזורות, אותיות חסרות (שני שלבים),
  מסתכלים-מכסים-כותבים, סדר א-ב, משפט עם כל מילה, וקלפי זיכרון לגזירה. אפשר להוסיף דף פתרונות.
- **4 משחקים במחשב**: משחק זיכרון, תפזורת, אותיות חסרות, ותראו ותכתבו.

## איך פותחים
לוחצים פעמיים על `index.html`. האפליקציה נפתחת בדפדפן, בלי התקנה.

## הדפסה
"הדפסה / שמירה כ-PDF" → לבחור מדפסת (או "שמירה כ-PDF"), גודל דף A4.
כדאי לסמן "גרפיקת רקע" בהגדרות ההדפסה, כדי שהמשבצות הצבעוניות יודפסו.
