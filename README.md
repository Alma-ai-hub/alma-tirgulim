# עלמה תירגולים

מכניסים 3-20 מילים (בעברית, באנגלית או גם וגם), נותנים שם למבדק, ומקבלים:

- **10 דפי עבודה להדפסה**, עם שם המבדק בגדול בראש כל דף. יש מאגר של 39 סוגי דפים
  בחמש קבוצות (כתיבה, חידות, איות, חשיבה, משחקי גזירה), ובכל מבדק נבחרים 10 אחרים:
  3 כתיבה, 3 חידות, 2 איות, 1 חשיבה, 1 משחק. אפשר להוסיף דף פתרונות.
- **8 משחקים במחשב**: משחק זיכרון, תפזורת, אותיות חסרות, תראו ותכתבו, אותיות מבולבלות, מי כתוב נכון, הצילו את הבלונים, ומירוץ הקלדה.
- **המבדקים שלי**: שמירת מבדק ופתיחה שלו מחדש, עם בדיוק אותם דפים.

## איך פותחים
לוחצים פעמיים על `index.html`. האפליקציה נפתחת בדפדפן, בלי התקנה.

## איפה נשמרים המבדקים
בדפדפן, במחשב הזה. אם פותחים את האפליקציה בדפדפן אחר, או מוחקים את נתוני הגלישה,
המבדקים השמורים לא יופיעו שם. כל מבדק שמור הוא רק השם, המילים ו"מספר ערבוב" (seed),
ולכן הוא תמיד נבנה מחדש עם אותם דפים בדיוק.

## הדפסה
"הדפסה / PDF" → לבחור מדפסת (או "שמירה כ-PDF"), גודל דף A4.
כדאי לסמן "גרפיקת רקע" בהגדרות ההדפסה, כדי שהצבעים הוורודים יודפסו.
